# Security policy

Nullify.WebMail handles mail credentials and OpenPGP keys, so security reports are very welcome.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Instead, use GitHub's private vulnerability reporting ("Report a vulnerability" on the [Security tab](https://github.com/simonsoanes/Webmail/security)) and include:

- the affected version or commit,
- steps to reproduce, or a proof of concept,
- the impact you expect.

You should get an acknowledgement within a few days. Fixes are released as a new version, and reporters are credited unless they would rather not be.

## Supported versions

Only the latest release receives security fixes.
